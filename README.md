# [alicegear-checker](https://s10az.github.io/alicegear-checker/)

武装カスタマイズアクションゲーム「 [アリス・ギア・アイギス](https://colopl.co.jp/alicegearaegis/) 」のスカウト率チェッカーアプリ

現在までに実装されているアクトレスの所持率を確認できるアプリです。
**コラボアクトレス、ガイアノーツや競艇組のアンバサダーアクトレスは含みません。**

## Development

```bash
echo "LAST_UPDATED=$(date +%Y-%m-%d)" > .env
pnpm install
pnpm dev
```
